# Roadster wallpapers

Ten lossless 8K images from user-supplied photographs and artwork. 01-wall-ride-8k.png is first in Omarchy's sorted list. Each has two contextual enhancement passes; original framing and aspect ratio are preserved except for Starlight, which is AI-extended sideways to 16:9. See ../CREDITS.md and ../SHA256SUMS.

The hover image uses lossless WebP, verified pixel-identical to its PNG master; the other nine remain PNG. Original PNG masters are retained in the separate wallpaper download.
